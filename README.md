# My Platformer: playtest builds

Latest playtest build of a Game Boy Color game made in GB Studio. Play it or download the ROM at the GitHub Pages site for this repo.

Generated by `tools/publish-playtest.mjs` in the game's source project. The source isn't in this repo.

## Kota Chomp DX

A second game's playtest build lives here too: `kotachomp.html` (page), `kotachomp-dx.gbc`
(download) and `kotachomp/` (browser player). Those three are hand-written and are NOT touched by
`publish-playtest.mjs`, which rewrites `index.html` whole - so the link to them ON the front page
is lost at the next platformer publish, while the page itself keeps working. Put that link in the
publisher's template to keep it.

Built from the GB-C-V3 project of the Kota Chomp source repo (`kotachomp-dx.gbsproj`).
